Run the [read-only verifier](../../../scripts/verify_generated_image_evidence_split.py)
from the repository root:

```bash
python scripts/verify_generated_image_evidence_split.py
python scripts/verify_generated_image_evidence_split.py \
  --archive "$ARCHIVE_DIR/edgeforge-generated-images-2026-10-17-sanitized.tar"
```

Exit 0 means integrity verified, not security acceptance. Exit 2 means incomplete
or mismatched evidence; exit 1 is never an error classification. Repository mode
needs neither Git history nor the private archive. Archive mode additionally
checks its full checksum, exact member set, safe extraction, all indexed gzip
and decompressed-JSON hashes, and byte equality with the repository core.

## Reproducibility Tiers And Publication Boundary

| Tier | Available proof and limits |
| --- | --- |
| 1. Clean clone | Conclusions/dispositions, ledger totals, coverage, per-stage identities, failure/recovery lineage and startup records; byte-identical Maven reconciliation from retained packaged inventories plus committed policy/baseline. |
| 2. Sanitized archive | Complete reviewed scanner reports, inventories, receipts and gaps; member-by-member integrity checks. Re-normalizing sanitized scanner inputs is untested and not claimed. |
| 3. Private originals | Campaign revalidation and historical republication require retained originals and the original tools/redaction roots, or the documented explicit prefixes. The clone/archive alone cannot provide those private preimages. |
| 4. Images not replayable | 57 exports were removed under the recorded policy; three representative final exports remain private. Rebuilds/rescans are new observations, not replay of all assessed images. |

Routine CI does not inspect gzip member contents; the campaign, publisher guard
and independent reviews performed decompressed checks, re-run on the core for
this change. See the [tooling review](../generated-image-tooling-review-2026-10-17.md)
for the distinct plain-file and archive-depth secret-scan scopes.

Third-party-content review applies to anything published (Git, archive or
historical PR refs). #331's refs remain reachable and may become public; this
reduces main's history, it does not erase prior uploads. The replacement must
merge with a **merge commit, not squash**, preserving the assessed generator and
tooling ancestry. #331 remains an unchanged historical review record until the
maintainer separately closes it as superseded.
